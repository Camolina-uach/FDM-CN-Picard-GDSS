# Changelog

## 1.0.1 — 2026-10-14

- Documentation only: the README and `CITATION.cff` no longer name a journal
  for the submitted manuscript, and both now point to the companion
  FFT–Strang article (doi:10.1142/S0129183127501671).
- `CITATION.cff` gives the Zenodo concept DOI (10.5281/zenodo.23030676), which
  resolves to the latest version, and lists the DOI of version 1.0.0.
- Two comments in `code/gdss_fdm_experiments4.py` no longer name a journal.
- No executable code, reference table, figure, or numerical result changed:
  `run_all.py` reproduces the outputs of version 1.0.0.

## 1.0.0 — 2026-09-29

- First public release of the reproduction package for the manuscript "A
  conservative Crank–Nicolson–Picard finite-difference scheme for the
  generalized Davey–Stewartson system: discrete invariants and benchmark
  validation".
- Solver (`code/gdss_fdm_solver.py`), experiment drivers for every figure and
  table of the manuscript, the single driver `run_all.py`, and the archived
  reference CSV tables in `reference_results/`.
- The figures and LaTeX tables of the manuscript, as generated by `run_all.py`,
  are included under `paper/Images/` and `paper/results_fdm/`; the manuscript
  source itself is not included.
- The collision experiment also writes print-size `|u|` and `Q` panels
  (`collision_absu.png`, `collision_Q.png`) used in the journal version.
